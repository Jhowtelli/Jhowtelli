Como desenho os fluxos

Cada agente tem
um trabalho definido.

Os projetos separam interpretação do modelo de cálculos e consultas que podem ser verificados.

01 / CONTEXTO

Receber a tarefa

O sistema define a pergunta e os dados necessários antes de encaminhar o pedido.

02 / ROTEAMENTO

Escolher o especialista

O coordenador direciona a tarefa ao agente que tem o papel adequado.

03 / FERRAMENTAS

Consultar e calcular

Funções locais retornam registros, agregações ou cenários determinísticos.

04 / RESPOSTA

Explicar com limites

A resposta mostra o que foi encontrado e deixa a decisão com a pessoa.

Os três projetos de IA são protótipos de portfólio. As demonstrações estáticas não chamam um modelo; os backends podem ser executados localmente com uma chave de API própria. Nenhuma chave está nos repositórios.
